# MCU Hardware for Switch Debounce and Electric Instrument Effects Switching

## Overview

This is the companion repo to [mcu-bypass-firmware](https://github.com/matt-garman/mcu-bypass-firmware).

These hardware designs are intended to be used for electric
instrument effects (e.g. guitar effect pedals) bypass switching.
Many of these schemes rely on a microcontroller to act as the
"brains" of the switching scheme; see the other repo for MCU
firmware.
